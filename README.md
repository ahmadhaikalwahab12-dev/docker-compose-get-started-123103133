# Docker Compose Get Started - 123103133

Mengikuti artikel Docker Compose Quickstart:
https://docs.docker.com/compose/gettingstarted/

Aplikasi: Flask + Redis (hit counter).

## Menjalankan
docker compose up --watch
Buka http://localhost:8000

## Langkah yang dikerjakan
1. Setup project (app.py, requirements.txt, Dockerfile, .env, .dockerignore)
2. Define and start services (compose.yaml)
3. Health check Redis
4. Compose Watch
5. Named volumes
6. Multiple Compose files (include)
7. Inspect dan debug (config, logs, exec)
